# Andrew Rogers - Portfolio

Personal portfolio for Andrew M. Rogers, a robotics software engineer focused on embedded systems, production delivery, and reliable real-world products.

[View the live site](https://andrwrgrs.github.io)

## Local preview

The site is intentionally dependency-free. From the repository root, run:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
