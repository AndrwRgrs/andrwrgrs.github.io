# Andrew Rogers - Portfolio

Personal portfolio for Andrew M. Rogers, a robotics and mechatronics engineer focused on real-time controls, embedded systems, hardware integration, and production delivery.

[View the live site](https://andrwrgrs.github.io)

## Local preview

The site is intentionally dependency-free. From the repository root, run:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
